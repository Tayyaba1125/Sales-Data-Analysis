# Sales Data Analysis Report

An interactive Power BI report analyzing sales data from 2020 to 2024, covering top and bottom products, city-wise sales, promotion performance and period comparison.

## Key Insights

- Total sales: **122M**, total profit: **12.2M**, total orders: **3.51K**
- **Apple iPhone 14** is the top product by sales, quantity and profit
- **Weekend Flash Sale** has the highest discount among promotions
- Sales and profit show a strong positive relationship

## Tools Used

Power BI, Power Query
